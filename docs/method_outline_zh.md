# 方法框架概述

[English](method_outline.md)

本项目将扑翼飞行器仿真环境与控制先验引导的策略学习相结合。前期工作对应 ACAIT 阶段，当前稿件将方法命名为**漂移感知近端策略优化（Drift-Aware Proximal Policy Optimization，DA-PPO）**。以下仅说明当前框架的概念流程。

## 概念框架

**控制先验初始化。** 反馈控制器生成示范，为学习提供初始控制行为。行为克隆将示范中的行为迁移到策略，作为后续交互学习的起点。

**漂移感知学习。** 初始化后的策略与仿真器交互。学习过程同时考虑持续位置偏差与飞行器近期响应，在 PPO 框架中联合改进策略与价值模型，并逐步考虑更长时间范围内的运动。

**控制接口。** 参考与仿真状态为控制器提供输入信息。控制器给出执行机构命令，仿真器推进飞行器动力学。仿真环境与学习控制器在这一闭环中分别承担各自的职责。

## 概念性伪代码

以下仅表达阶段关系，不定义可执行操作或实现细节：

```text
控制先验初始化
    获取反馈控制示范。
    通过行为克隆形成初始策略。

漂移感知策略学习
    从初始化策略开始。
    通过与仿真器交互获取控制经验。
    在表示和评价控制行为时考虑持续偏差。
    在漂移感知 PPO 框架中改进策略与价值模型。
    逐步扩展学习所考虑的运动时域。

控制器使用
    将学习策略连接到参考、状态与执行机构接口。
```
